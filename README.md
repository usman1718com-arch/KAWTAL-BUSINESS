# KAWTAL BUSINESS

Prototype mobile-first d'interface de gestion pour les PME guinéennes.

## Ouvrir le prototype
Ouvrir `index.html` dans un navigateur ou publier le dossier sur un hébergeur statique.

## Contenu
- Tableau de bord de démonstration
- Indicateurs fictifs
- Actions rapides de démonstration
- Dernières opérations fictives

## Important
Cette version est une maquette front-end. Elle ne possède pas encore de connexion, de base de données, de sauvegarde réelle ni de paiements. Les données affichées sont des exemples.
